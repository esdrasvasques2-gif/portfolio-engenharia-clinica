# Portfólio — Engenharia Clínica & TI em Saúde

Site institucional estático em HTML, CSS e JavaScript, preparado para GitHub Pages.

## Antes de publicar
1. Substitua os campos `[NOME DA EMPRESA]`, `[TELEFONE]`, `[DDDNUMERO]`, `[EMAIL]`, `[SITE OU LINKEDIN]`, `[NOME DO RESPONSÁVEL]` e `[CARGO]` em `index.html`.
2. Atualize o link do WhatsApp `https://wa.me/55[DDDNUMERO]` com código do país, DDD e número, apenas dígitos.
3. Confirme cobertura de prestadores, capacidade técnica, registros e responsabilidades antes de anunciar serviços especializados.
4. Revise os textos institucionais e os contatos.

## Publicar no GitHub Pages
1. Entre em https://github.com e crie um repositório público chamado `portfolio-engenharia-clinica-ti-saude`.
2. Envie `index.html`, `styles.css`, `script.js` e `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`; clique em **Save**.
6. Aguarde a publicação; a URL será exibida na área de Pages.

## Arquivos
- `index.html`: conteúdo
- `styles.css`: identidade visual responsiva
- `script.js`: menu móvel e ano automático

## Escopo e conformidade
O site descreve um modelo de gestão e fiscalização de prestadores terceirizados. Não declara clientes, certificações, resultados ou equipe própria não comprovados. Referências normativas não equivalem a declaração de conformidade.
